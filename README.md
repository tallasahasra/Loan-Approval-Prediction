# Loan Approval Prediction Using Machine Learning

## 📌 Project Overview

This project develops a supervised machine learning model to predict whether a loan application will be **Approved** or **Rejected** based on applicant information.

The project focuses on data preprocessing, handling missing values, categorical encoding, feature scaling, class imbalance handling, model comparison, evaluation, and business-oriented interpretation.

## 🎯 Objectives

* Clean and preprocess the loan application dataset
* Handle missing values
* Encode categorical variables
* Scale numerical features
* Handle class imbalance using SMOTE
* Train multiple classification models
* Compare model performance
* Evaluate Precision, Recall, F1-score, and ROC-AUC
* Perform classification threshold analysis
* Provide business insights for loan approval decisions

## 📊 Dataset

The project uses the **Loan Approval Prediction Case Study** dataset from Kaggle.

Important features include:

* Gender
* Married
* Dependents
* Education
* Self_Employed
* ApplicantIncome
* CoapplicantIncome
* LoanAmount
* Loan_Amount_Term
* Credit_History
* Property_Area
* Loan_Status

`Loan_ID` was removed because it is an identifier and does not provide useful predictive information.

## 🔧 Data Preprocessing

The following preprocessing steps were performed:

1. Identified missing values.
2. Used median imputation for numerical features.
3. Used most-frequent-value imputation for categorical features.
4. Applied One-Hot Encoding to categorical variables.
5. Applied StandardScaler to numerical features.
6. Split the dataset into 80% training and 20% testing data.
7. Used SMOTE on the training data to address class imbalance.

## 🤖 Machine Learning Models

Three classification algorithms were compared:

1. Logistic Regression
2. Decision Tree
3. Random Forest

## 💼 Business Interpretation

The model can be used as a decision-support tool for financial institutions to help evaluate loan applications.

A lower threshold may classify more applications as approved but could increase incorrect approvals. A higher threshold provides a more conservative strategy but may reject some potentially eligible applicants.

Therefore, the threshold should be selected according to the organization's risk tolerance and the relative cost of false approvals and false rejections.

The model should support human decision-making rather than completely replace it.
